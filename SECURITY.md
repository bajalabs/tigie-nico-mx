# Security policy / Política de seguridad

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for
a security problem. We aim to acknowledge a report within five working days.

In scope: the code in this repository (the parser, the capture step that downloads and converts the
Cámara de Diputados' files, the exporters) and its CI workflow.

A wrong duty, date or description is a data error, not a security issue: report it with the
"Data error / Error en los datos" issue template.

## Reportar una vulnerabilidad

Reporte los problemas de seguridad en privado con el reporte privado de vulnerabilidades de GitHub
(pestaña **Security**, **Report a vulnerability**), nunca en un *issue* público. Un arancel, una
fecha o una descripción equivocados son errores de datos: use la plantilla «Error en los datos».
